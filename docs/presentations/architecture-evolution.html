Security became a defined contract

Spec 0004 · OD-4 closed June 18

  • Shared tables carry tenant_id. Transaction-bound RLS provides a backstop.
  • Uploads default to owner-only access. Explicit grants widen access.
  • App-managed authentication uses Argon2id, short-lived JWTs, and rotating refresh tokens.
  • Cross-tenant and inaccessible resources return 404.
  • Malformed input uses 422. Illegal transitions use 409.
  • The specification records OIDC via Keycloak as the future SSO default.
Sources:Security invariants
Speaker notes. INV-1 through INV-8 pin tenancy, permissions, citations, authentication, roles, audit, approval, and validation/transition behavior to negative tests. Keycloak is a decided end-state default, not a shipped identity provider. The RLS backstop requires a non-superuser, non-BYPASSRLS application role. The local compose lumen role is documented as a superuser, so local RLS is not a production isolation proof.

Why the original retrieval store changed

ADR-0010 · lexical relevance and corpus scale

Original. pgvector similarity and PostgreSQL full-text produce rankings that Python fuses with reciprocal-rank fusion.

Pressure. Phrase/proximity search, fuzzy matching, synonyms, field boosting, and native highlights require richer lexical controls.

Chosen target

BM25 and vector kNN in one retrieval engine, with engine-side hybrid ranking.
